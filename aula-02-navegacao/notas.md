# Aula 2 — Navegação de Arquivos

## O que aprendi

- "Diretório atual" é a pasta onde você está navegando no momento dentro do sistema.
- É possível confirmar se uma ação de navegação funcionou usando `dir` antes e depois.

## Comandos praticados

| Comando | Função |
|---|---|
| `dir` / `ls` | Lista arquivos e pastas do diretório atual |
| `cd [pasta]` | Entra em uma pasta |
| `cd ..` | Volta uma pasta |
| `cd \` | Vai direto para a raiz do disco (C:\) |

## Lição principal

Sempre confirmar o resultado de uma navegação com `dir` — nunca assumir que a ação funcionou sem verificar.
