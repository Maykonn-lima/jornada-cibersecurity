# jornada-cibersecurity
Documentando minha jornada de TI ao IAM, começando do zero.

## 🎯 Objetivo

Construir uma carreira em Segurança da Informação, com foco em IAM, através de:
- Trilha: Helpdesk → SOC → IAM → IAM Engineer
- Aprendizado prático, documentando inclusive os erros no caminho

- Aula 1 — Processos e Linha de Comando (PowerShell)
- Aula 2 — Navegação de Arquivos
- Aula 3 — Criar/Apagar Arquivos e Pastas
